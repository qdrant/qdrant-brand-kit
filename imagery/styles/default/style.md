# Image style: Default

The original Design Lab moodboard: space and astronaut scenes. Used when a request doesn't name another style.

The 10 images in `references/` set the look: palette, lighting, materials and mood. Every one is sent with every generation, in slot order, resized to 1024 px.

## Guidance

Empty in Design Lab today (`brand-kit/guidance/styles/default.md`). Write here only what the references can't show on their own:

- the kind of world scenes are set in
- the subjects that belong in it
- how the camera usually frames them
- what this style never shows
