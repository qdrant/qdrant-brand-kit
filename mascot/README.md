# Mascot

Qbot, the Qdrant mascot, as a Design Lab primitive. Two styles, each a handoff package with its own README.

| Style | Folder | What it is |
| --- | --- | --- |
| 3D | [`3d/`](3d/) | The main mascot, used most often. 14 approved poses, prompt pack and scripts. Shared with Neil on 2026-10-21, updated to the 2026-10-23 routing decisions. |
| 2D | [`2d/`](2d/) | The cartoon Qbot as a second style. 5 approved poses, 2D-only references so it never drifts toward 3D. Shared with Neil on 2026-10-29. Start with `2d/docs/brief-2d.md`. |

## Shared rules

- **Transparent PNG only.** One generation per new pose. Approved poses are free to download.
- **Never mix styles.** 3D generations use 3D references only, 2D generations use 2D references only.

## Notes

- Unlike the other primitives, the mascot needs images: `references/` are model inputs. `previews/` and `samples/` are only for checking the look.
