# Compositions

Approved layouts an agent can choose from. Each one names the slots (title, body, speakers, logos, button, image…), where they go on the grid per shape, and which gaps sit between them.

**None approved yet.** Until there are some, an agent should say so and ask before laying out a creative.

## Adding one

One file per composition, `<name>.md`, with:

- **Sketch:** a picture of it on every shape it supports.
- **Use it for:** e.g. event with speakers, product announcement, customer stat.
- **Shapes:** which of ultrawide, wide, square, portrait and story it works on.
- **Slots per shape:** column start and span, order, and the gap role between each slot.
- **Approved by / date.**
